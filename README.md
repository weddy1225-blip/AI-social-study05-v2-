# 🏛️ 小小地方官 - 社會實踐決策模擬器

這是一個專為公民與社會教育設計的互動式遊戲。透過模擬地方官員處理陳情案件的過程，引導學生學習「優先順序」的概念，並建立「生命權高於生活品質」的核心價值觀。

## 🎮 立即體驗
[點擊這裡開始遊戲](https://weddy1225-blip.github.io/AI-social-study05-v2-/)

## 🌟 設計特點

### 1. 去標籤化挑戰
移除所有顏色提示。學生必須透過閱讀文字，判斷案件屬於「安全（生命權）」、「鄰里（安寧環境）」、「建設（硬體設施）」還是「文化（在地記憶）」，杜絕靠顏色配對作弊的可能性。

### 2. 動態互動導引
遊戲頂端的導引文字會隨著學生的放置動作自動更新（例如：從第 1 優先切換至第 2 順位提示），確保操作流程流暢且明確。

### 3. 多元社區反饋系統
內建 **10 位性格鮮明的角色**（如毒舌評論家、網紅、退休隊長等），隨機根據學生的正確與錯誤決策給出「紮心」或「溫情」的評語，增加遊戲的趣味性與代入感。

### 4. 嚴肅的價值教育
系統嚴格判定「生命安全（Safety）」類別為最高優先。若學生忽略具傷亡風險的案件，AI 秘書長會給出嚴厲警告與低分評價，反之則給予高度讚賞。

## 🛠️ 技術規格
- **技術棧**: 純原生 HTML5, CSS3, JavaScript (無須額外框架)。
- **核心功能**: 拖放 API (Drag and Drop)、響應式佈局 (Responsive Design)。
- **支援設備**: 電腦瀏覽器、平板及智慧型手機（已優化 Touch 操作）。

## 📖 如何使用
1. 下載 `index.html`。
2. 直接使用瀏覽器開啟即可開始教學演示或學生體驗。
3. 建議在提交後引導學生討論：*「為什麼這個角色會對我的決策感到失望？」*。

## ⚖️ 教育意義
本遊戲旨在探討「公共行政中的檢傷分類」，讓學生理解資源有限的情況下，如何根據人權原則做出最具倫理價值的選擇。
